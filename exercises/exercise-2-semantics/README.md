# Exercise 2: Semantic HTML Structure

## 🎯 Objective
Replace generic `<div>` tags with modern semantic tags to improve accessibility, structure, and SEO.

## 📋 Requirements
Inside `index.html`:
1. Use a `<header>` element containing the academy name in an `<h1>` and a navigation menu `<nav>`.
2. Inside `<nav>`, include an unordered list `<ul>` with at least 3 list items `<li>` with links `<a href="...">` (Home, Courses, Contact).
3. A `<main>` element containing:
   - An `<article>` representing an article about High Q Academy.
   - Inside the article, an `<h2>` heading and at least one `<p>` paragraph.
   - An `<aside>` containing related information or quick facts.
4. A `<footer>` element at the bottom containing copyright text.
