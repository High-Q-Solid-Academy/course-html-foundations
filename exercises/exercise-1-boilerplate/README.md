# Exercise 1: HTML5 Document Boilerplate

## 🎯 Objective
Create a valid HTML5 document structure with essential meta tags and page title.

## 📋 Requirements
Inside `index.html`:
1. Include `<!DOCTYPE html>` at the top.
2. An `<html lang="en">` root element.
3. A `<head>` containing:
   - `<meta charset="UTF-8">`
   - `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
   - A `<title>` element with "High Q Solid Academy - Welcome"
4. A `<body>` containing:
   - An `<h1>` heading with the text "Welcome to High Q Solid Academy"
   - A `<p>` paragraph with the academy motto: "Always Ahead of Others"
