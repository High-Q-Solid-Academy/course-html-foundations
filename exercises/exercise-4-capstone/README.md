# Exercise 4: Capstone — High Q Academy Course Landing Page

## 🎯 Objective
Combine all your knowledge (document head, semantic structure, typography, media, lists, tables, and forms) to build a complete landing page for High Q Solid Academy.

## 📋 Requirements
Inside `index.html`:
1. Valid HTML5 boilerplate with complete meta tags.
2. `<header>` with an `<img>` logo (use `alt="High Q Solid Academy Logo"`), `<h1>` title, and `<nav>` with navigation links.
3. `<main>` element with:
   - A hero `<section>` with an `<h2>` heading and the motto "Always Ahead of Others".
   - A programs `<section>` featuring a `<table>` comparing the 4 tracks (Course Name, Duration, Prerequisites).
   - An admission `<section>` containing the accessible enrollment form from Exercise 3.
4. `<footer>` with social links (Telegram, Website, TikTok, X) and address in Ikorodu, Lagos.
