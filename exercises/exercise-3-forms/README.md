# Exercise 3: Accessible Student Registration Form

## 🎯 Objective
Create a user-friendly, fully accessible HTML5 web form for student enrollment at High Q Solid Academy.

## 📋 Requirements
Inside `index.html`:
1. A `<form>` element with an `action="#"` and `method="POST"`.
2. A `<label for="fullname">Full Name</label>` paired with `<input id="fullname" name="fullname" type="text" required>`.
3. A `<label for="email">Email Address</label>` paired with `<input id="email" name="email" type="email" required>`.
4. A `<label for="course">Select Track</label>` paired with a `<select id="course" name="course">`:
   - Include options: "Git & GitHub", "HTML Foundations", "CSS Mastery", "JavaScript Core".
5. A `<label for="comments">Comments</label>` paired with a `<textarea id="comments" name="comments">`.
6. A `<button type="submit">Enroll Now</button>`.
