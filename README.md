# 🌐 HTML5 Foundations — High Q Solid Academy

Welcome to **HTML5 Foundations** at **High Q Solid Academy**. HTML (HyperText Markup Language) is the fundamental skeleton of every webpage and web application on the internet.

---

## 🎯 What You Will Master
- The standard anatomy of an HTML5 document (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Viewport and SEO meta tags (`meta charset="UTF-8"`, `meta name="viewport"`, `<title>`)
- Modern **Semantic HTML5 tags** (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`)
- Accessible typography, lists (`<ul>`, `<ol>`), and hyperlinks (`<a href="..." target="_blank">`)
- Responsive media embedding (`<img>` with accessible `alt` text, `<figure>`, `<figcaption>`)
- Building accessible, validated web forms (`<form>`, `<label for="...">`, `<input required>`, `<button>`)
- Semantic data tables (`<table>`, `<thead>`, `<tbody>`, `<th scope="col">`)

## 🚀 How to Complete Exercises & Get Graded

1. Clone this repository locally to your computer.
2. Open the project in VS Code.
3. Run `npm install` in your terminal to install the grading suite.
4. Work through each exercise folder in `exercises/`.
5. Run the tests locally at any time:
   ```bash
   npm test
   ```
6. Push your commits to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete html exercises"
   git push origin main
   ```
7. GitHub Actions will automatically run the autograder and award your points!
